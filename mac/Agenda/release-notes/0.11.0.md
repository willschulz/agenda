# Agenda 0.11.0

- **iPhone and iPad sync.** On a Mac signed in to iCloud, Agenda keeps a copy of your board in your own private iCloud database, so the Agenda companion app for iPhone and iPad (in TestFlight) can show and edit it. Only your Apple ID can read that database; the developer can't see it. Your Mac remains the source of truth.
- **Agent tools (MCP).** Settings → Agent tools (MCP) gives you a one-line command to connect Claude Code, or a configuration for other MCP clients, so agents can read your board and track their work on it through tools that follow Agenda's workflow rules.
- **Claude usage limits** can be connected with one click in Settings.
- **Board order** is now one setting for every row: by recent activity, or in the order you arrange.
- Fixes the completed-history window opening off-center with its list collapsed.
