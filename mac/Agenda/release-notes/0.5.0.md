# Agenda 0.5.0

- Uses Apple’s on-device Foundation Models framework first when shortening long
  todo descriptions on supported Macs.
- Enforces a deterministic title contract: one line, at most eight words and
  60 characters, with `FR:`, `BUG:`, and `NIT:` prefixes preserved.
- Keeps the full original todo description in its context notes.
- Falls back to configured remote providers and then safe local truncation when
  the on-device model is unavailable.
- Prevents a delayed Keychain lookup from blocking Agenda’s window and local
  server during startup.
