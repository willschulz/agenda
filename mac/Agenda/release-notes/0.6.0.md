# Agenda 0.6.0

Agenda now has a clean local/frontier AI boundary.

- Removed the legacy LLM service URL and its tailnet dependency.
- Kept concise todo titles local-first with Apple Foundation Models, optional
  OpenAI fallback, and deterministic fallback.
- Moved clarifying detail suggestions to the optional frontier provider with
  strict structured-output validation.
- Reported title, detail-suggestion, and assistant capabilities independently
  so unavailable controls stay hidden.
- Removed the retired service URL from existing app preferences automatically.
