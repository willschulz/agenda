# Agenda 0.3.0

This release establishes the shared update and support channel.

- Adds automatic local database snapshots on startup and every six hours.
- Shows actionable diagnostics and a retry button if the embedded server
  cannot start.
- Adds **Report a Problem** with version and recent server logs prefilled.
- Adds **Check for Updates** and automatic updates powered by Sparkle.

Agenda 0.2.0 cannot update itself, so 0.3.0 is the final release that needs to
be installed manually. Future releases can update in place.
