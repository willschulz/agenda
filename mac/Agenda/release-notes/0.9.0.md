# Agenda 0.9.0

- Uses a rounded Mac app icon in the Dock and Finder.
- Adds a Recents menu for recently touched todos.
- Shows a todo's id above its title on hover.
- Evens out spacing between single-line and multi-line titles.
- Keeps lab-note links readable in dark mode.
- Opens note links in Chrome.
- Moves Add todo into each project card, inserts a new todo at the top of its group, and lets you insert one between existing tasks.
- Keeps the new-todo field focused after you add a task, and types into search when the board is filtered.
- Fixes a freeze after rearranging tasks and lag after status clicks.
