# Agenda 0.10.5

- The board refreshes with about half as much data. Todo notes now load once in the background and then only when they change, instead of being re-sent on every update. Search still covers notes; for the first second or so after Agenda opens, it matches todo titles only until notes have loaded.
- Agents and scripts can request the lighter board with `GET /api/projects?todo_notes=summary` and fetch note text with `GET /api/todo-notes`. The default `/api/projects` response is unchanged.
