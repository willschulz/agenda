# Agenda 0.10.0

Agenda is now open source under the GPL: https://github.com/willschulz/agenda

- Edit your board's rows: Settings → Edit Rows lets you rename, add, reorder, and delete rows. Deleting a row asks which row its projects should move to.
- New boards open a short welcome tour and start with Correspondence, Life Stuff, and Work Miscellany in Top of Mind.
- Usage-limit dials show how fast you're using your Claude and Cursor subscription limits, for whichever tools you use.
- AI usage now shows each project's share by tool. You can also record what you pay for each tool and see that cost split across projects.
- Search finds todos by task number (#123 or 123).
- Clicking a todo's hover number copies its #id and short title.
- Hovering the right side of the gap between two todos inserts a subtask under the todo above.
- Removes the agent-pickup and lookup copy buttons from todo cards.
- Before an update changes your database's structure, Agenda now saves a backup of it first. This update does that once, when it converts your rows to the new editable format.
