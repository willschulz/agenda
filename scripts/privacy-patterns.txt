# Generic patterns that must never appear in the public tree.
# One extended regex per line (ripgrep syntax, matched case-insensitively).
# Maintainer-specific terms (hostnames, project names, people) belong in
# .privacy-patterns.local, which is gitignored and read in addition to this file.

# Personal filesystem locations
/Users/[A-Za-z0-9._-]+/
/home/[A-Za-z0-9._-]+/
/Volumes/

# Private networks and tailnets
\b192\.168\.[0-9]{1,3}\.[0-9]{1,3}\b
\b10\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\b
\b100\.(6[4-9]|[7-9][0-9]|1[01][0-9]|12[0-7])\.[0-9]{1,3}\.[0-9]{1,3}\b
\.ts\.net\b

# Personal email providers (project contact goes through GitHub)
@(gmail|icloud|me|outlook|hotmail|yahoo)\.com\b
